Preguntas y respuestas

¿Cuál es la diferencia entre Internet y la World Wide Web?

Internet es la infraestructura: una red global de computadoras interconectadas que permite la comunicación entre dispositivos.

La World Wide Web (WWW) es un servicio que funciona sobre Internet y consiste en páginas web interconectadas mediante hipervínculos.

En otras palabras, Internet es la red; la Web es uno de los servicios que usamos dentro de esa red.

¿Cuáles son las partes de un URL?

Un URL se compone de varias partes que identifican y localizan un recurso:

  • Protocolo: indica cómo se comunican los datos, por ejemplo http o https.
  • Dominio: nombre del servidor, por ejemplo google.com.
  • Puerto: canal de comunicación, como 80 para HTTP o 443 para HTTPS.
  • Ruta: recurso solicitado, por ejemplo /login.
  • Query string: parámetros adicionales, por ejemplo ?id=10&user=juan.
  • Fragmento: referencia interna en el documento, por ejemplo #seccion, que no se envía al servidor.

Cada parte cumple una función específica para ubicar y acceder al recurso solicitado.

¿Cuál es el propósito de los métodos HTTP: GET, HEAD, POST, PUT, PATCH y DELETE?

Los métodos HTTP indican qué acción desea realizar el cliente sobre un recurso en el servidor.

  • GET: obtener datos sin modificarlos.
  • HEAD: igual que GET, pero sin devolver el contenido del recurso.
  • POST: enviar datos o crear un recurso.
  • PUT: reemplazar completamente un recurso.
  • PATCH: modificar parcialmente un recurso.
  • DELETE: eliminar un recurso.

Estos métodos son fundamentales para definir operaciones en aplicaciones web y APIs.

¿Qué método HTTP se debe utilizar al enviar un formulario HTML?

El método que normalmente se utiliza es POST. Esto se debe a que envía los datos en el cuerpo de la petición y no directamente en la URL.

También es más adecuado para datos sensibles, como usuarios o contraseñas, y permite enviar una mayor cantidad de información. Aun así, la seguridad real depende de utilizar HTTPS.

¿Qué método HTTP se utiliza cuando se accede a una página mediante un URL?

Se utiliza el método GET, porque el navegador solicita obtener un recurso sin modificarlo.

¿Qué significa un código HTTP 200? ¿Ocurrió algún error?

El código 200 OK significa que la solicitud fue exitosa y que el servidor devolvió correctamente el recurso solicitado. No ocurrió ningún error.

Por lo general, los errores corresponden a códigos 4xx o 5xx.

¿Es responsabilidad del desarrollador corregir un error 404?

Sí, generalmente sí. Un error 404 significa que el recurso no fue encontrado. Esto puede suceder por enlaces rotos, URLs mal definidas o recursos eliminados sin redirección.

En muchos casos, el desarrollador debe revisar la estructura del sitio y corregir esos enlaces o configurar redirecciones adecuadas.

¿Es responsabilidad del desarrollador corregir un error 500?

Sí, totalmente. El error 500 indica un fallo interno del servidor. Generalmente está relacionado con problemas en el código backend, errores de lógica o una mala configuración del servidor.

¿Qué significa que un atributo o elemento HTML5 esté desaprobado?

Significa que ya no se recomienda su uso, porque ha sido sustituido por prácticas más modernas o porque podría eliminarse en futuras versiones del estándar.

Algunos ejemplos de elementos desaprobados de HTML 4 en HTML5 son:

  • <font>
  • <center>
  • <big>
  • <frameset>

¿Cuáles son las diferencias principales entre HTML 4 y HTML5?

HTML5 introduce etiquetas semánticas como <header>, <section> y <footer>; además, ofrece soporte multimedia nativo con <audio> y <video>, e incluye APIs modernas.

HTML 4 era menos semántico y dependía más de tecnologías externas, como plugins, para algunas funciones multimedia.

En general, HTML5 es más moderno, estructurado y adecuado para aplicaciones web actuales.

¿Qué componentes de estructura y estilo tiene una tabla?

En cuanto a la estructura, una tabla utiliza elementos como:

  • <table> para la tabla
  • <tr> para las filas
  • <td> para las celdas
  • <th> para los encabezados

El estilo visual de una tabla, como bordes, colores o tamaños, normalmente se aplica con CSS.

¿Cuáles son los principales controles de una forma HTML5?

Los principales controles de una forma HTML5 son:

  • <input> en sus diferentes tipos, como text, email, password y number
  • <textarea> para texto largo
  • <select> para listas desplegables
  • <button> para ejecutar acciones
  • <label> para identificar campos

Estos elementos permiten capturar y organizar la información que introduce el usuario.

¿Cuál es el ciclo de vida y el ciclo de desarrollo de los sistemas de información?

El ciclo de vida de los sistemas de información incluye las etapas de:

  1. Planeación
  2. Análisis
  3. Diseño
  4. Implementación
  5. Mantenimiento

Por otro lado, el ciclo de desarrollo de sistemas de información (SDLC) considera normalmente:

  1. Requisitos
  2. Diseño
  3. Desarrollo
  4. Pruebas
  5. Despliegue
  6. Mantenimiento

Ambos describen las etapas necesarias para crear, implementar y mantener sistemas desde la idea inicial hasta su operación continua.
